# IBM Plex web fonts

Self-hosted Latin WOFF2 subsets of IBM Plex Sans (400, 500, 600) and IBM Plex Serif (400), distributed by Fontsource from IBM Plex. These subsets include the accented Latin characters used in the portfolio.

- Upstream: https://github.com/IBM/plex
- Distribution: https://fontsource.org/fonts/ibm-plex-sans and https://fontsource.org/fonts/ibm-plex-serif
- License: SIL Open Font License 1.1; original copyright notices and license text are in `LICENSE-sans.txt` and `LICENSE-serif.txt`.

The fonts load locally. No font service or runtime package dependency is required.
